==================

   IDLSeries: Sequence container for temporal series of IDL .out / .outs files.
   Provides lazy-loaded LRU caching, header pre-scanning, temporal slicing,
   nearest-time frame lookup, and optional dataset concatenation.

.. py:class:: IDLSeries(files: Union[str, pathlib.Path, Sequence[Union[str, pathlib.Path]]], eager: bool = False, max_cache: int = 32, _headers: Optional[List[Dict[str, Any]]] = None)

   Bases: :py:obj:`Sequence`\ [\ :py:obj:`xarray.Dataset`\ ]


   Sequence container for a series of IDL (.out/.outs) output files.

   Provides fast metadata scanning, lazy loading with LRU cache, temporal slicing,
   and nearest-frame lookup by time or iteration.

   :param files: File path pattern (e.g. 'run/PC/*.out') or list of file paths.
   :type files: str or Sequence of (str or Path)
   :param eager: If True, loads all datasets into memory at initialization.
                 If False, loads datasets on-demand when indexed.
   :type eager: bool, default False
   :param max_cache: Maximum number of datasets to hold in memory when lazy loading.
   :type max_cache: int, default 32
